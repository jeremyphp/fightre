# Trademark policy

The Apache-2.0 license covers copyright and patents. Section 6 explicitly excludes
trademarks, which means the license says nothing about the name "FightRE" or the
project logo. This document fills that gap.

The intent is narrow: **keep forks distinguishable from the official project.** It
does not restrict any use of the code.

## What is covered

- The name **FightRE**
- The project logo and the wordmark
- The package name `fightre` on PyPI, and `fightre/*` container images

## You may, without asking

- Use the software for any purpose, commercial or not.
- State, factually, that your product **uses** or is **built on** FightRE:

  > "Uses FightRE for request attestation."
  > "Includes FightRE under the Apache-2.0 license."

- Redistribute the unmodified software under its own name, including the name
  FightRE, provided the NOTICE file is preserved.
- Write articles, talks, benchmarks, comparisons or criticisms that name the
  project.
- Use the name in a package dependency list, a `requirements.txt`, or a software
  bill of materials.

## You may not, without written permission

- Use the name or logo as the name of your product, company, service or domain.
- Use the name in a way that suggests endorsement, sponsorship or official status,
  e.g. "FightRE Pro", "FightRE Cloud", "official FightRE support" from an
  unaffiliated party.
- Distribute a **modified** version under the name FightRE. Rename your fork.

The distinction we care about is the last one: if behaviour differs, the name must
differ, because users reasonably assume the same name means the same verdict logic.

## Forks: rename, then everything is fine

Change the distribution name, the package name, and the README title, keep the
NOTICE file, and you may licence your derivative however Apache-2.0 permits (it
permits anything).

## Commercial use of the name

Deploying FightRE inside your company requires no permission and no trademark
action. You do not need to display attribution anywhere user-facing; the NOTICE
file in the source distribution satisfies Apache-2.0.

## Reporting misuse

Open a discussion in the repository, or use the security contact in
[SECURITY.md](SECURITY.md) if the matter is sensitive. We will always try to
resolve by clarification first.

This policy is adapted from common practice in Apache-2.0 projects and is not legal
advice. If you need certainty for a commercial use of the name, consult counsel.
